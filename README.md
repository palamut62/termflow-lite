# TermFlow Lite

A fast, free terminal for Windows and Linux. Tabs and splits, PowerShell, Git Bash, WSL and coding agents such as Claude Code and Codex, and every command marked as passed, failed or running.

**Website:** https://termflow-lite.vercel.app

## Download

Get the latest version from [Releases](https://github.com/palamut62/termflow-lite/releases/latest):

| Platform | File |
| --- | --- |
| Windows | `TermFlow-Lite-<version>-x64.exe` (installer) · `TermFlow-Lite-<version>-x64.zip` (portable) |
| Linux | `TermFlow-Lite-<version>-x86_64.AppImage` · `TermFlow-Lite-<version>-amd64.deb` |

Installed copies update themselves from this page.
