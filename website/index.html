Why TermFlow

tmux muscle memory, native on Windows

A workspace is a session, a window is a tab, and every window splits into a tree of panes. Real ConPTY terminals rendered with xterm.js — no WSL required.

Tiled panes by default

New terminals join the current window as tiled panes — everything on one screen, tmux style. Split further with % and ", or gather every window into one tiled layout with prefix + t. Tabs stay available as a secondary mode.

Persistent PTY daemon

Terminals live in a background daemon, so they keep running when you close TermFlow. Open it again and attach back to the same sessions, scrollback included — real detach and attach.

Copy mode & broadcast

vi-style scrollback navigation with search and yank, input broadcast to several terminals at once, and asciinema-compatible .cast recording.

Prefix key · windows · panes
Prefix key

Everything is one keystroke away

Press the prefix — Ctrl+A by default, or switch it to Ctrl+B — then a single key. Press the prefix twice to send the raw control byte straight to the terminal.

  • c new window · n / p next & previous · 0-9 jump
  • , rename window · d detach · x close
  • % split vertically · " split horizontally
  • h j k l or arrows to move between panes · o next pane · z zoom
  • t tile all windows into one screen
  • [ copy mode · ? in-app key reference
Copy mode · scrollback · search
Copy mode

Walk the scrollback without a mouse

Hit the prefix and [ to freeze the pane and move through history the vi way — then select, yank, and get straight back to work.

  • Character, word and line motions
  • Half-page and full-page scrolling
  • Space or v to start a selection
  • Enter or y to copy
  • / ? to search, n N to step through matches

Everything inside

Packed with features, none in your way

CLI tools like Claude Code, Codex, Gemini and Ollama are just launch profiles here — the same status as PowerShell, CMD, WSL or Git Bash. TermFlow starts them for you; it does not orchestrate them.

Terminals

  • Real ConPTY processes rendered with xterm.js
  • PowerShell, CMD, WSL, Git Bash and custom profiles
  • Tiled-by-default: new terminals open as panes on one screen
  • Vertical & horizontal splits in a binary pane tree
  • Pane zoom to focus one terminal full-window

Multiplexing

  • Workspace = session, window = tab, pane = split
  • Prefix key: Ctrl+A or Ctrl+B
  • Tab strip: switch, rename, drag-reorder, close
  • Detach and attach with the persistent PTY daemon

Workflow

  • Copy mode with vi motions, search & yank
