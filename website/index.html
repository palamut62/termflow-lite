Read a long session at a glance

Shell integration marks every command in PowerShell, Git Bash, bash and zsh. A green line means it passed, red means it failed, and slow commands show how long they took.

  • Ctrl ↑ and Ctrl ↓ jump between commands in a long scrollback
  • Right-click a command to copy its output, rerun it or copy it ready for an AI agent
  • A command that runs for more than 10 seconds in a background tab sends a notification when it ends

Run agents and shells side by side

Split the window, drag panes to re-tile them and keep Claude Code, Codex or OpenCode next to the shell that runs your tests.

  • Give each agent its own git worktree so parallel sessions never overwrite each other
  • Hand work from one agent or provider to another without losing the context
  • Tabs show live state: running, waiting for input, new output, done or failed

See what your agent is up to

Ember, Miso or Piko sits beside each agent terminal and acts out the real session: typing while it edits, thinking, waiting for your approval, cheering when it is done.

  • Its expression follows the session itself, never a guess from the output, and the caption names the work, like "Editing upload.ts"
  • After a long streak it keeps going with a tired face and the odd yawn. Leave it idle and it falls asleep
  • Drawn as ASCII or as pixel art, with a character per agent or the one you pick

Type less, find more

Commands you ran before appear as a grey suggestion while you type. Press → to take it.

  • Compiler and test errors like src/app.ts:42:7 open at that line in VS Code, Cursor or Windsurf
  • Search every command you ran with Ctrl Shift H
  • Run package.json scripts, Git and Docker tasks from the palette with Ctrl Shift P

Make it feel like yours

Fifteen themes and a custom palette editor, Mica and Acrylic backdrops on Windows 11, cursor trails and an optional retro CRT screen. Motion can be subtle, full or off, and the system reduce-motion setting always wins.

  • WebGL rendering, ligatures and inline images (Sixel and iTerm2)
  • Mechanical or soft key sounds, and confetti when your tests pass, if you want them

See your year in the terminal

Wrapped counts your commands, top tools, busiest hour and streaks, and hands out badges like Night Owl and Commit Machine. It is drawn like terminal output, in your terminal font and theme colors. Save it as an image to share.

Wrapped stores counters and tool names only, never arguments or output, and nothing leaves your machine.
